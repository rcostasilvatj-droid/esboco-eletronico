# Esboço Eletrônico

Aplicativo web instalável para organizar esboços de discursos e a presidência da reunião pública.

**by Ricardo Silva**

[Abrir o Esboço Eletrônico](https://rcostasilvatj-droid.github.io/esboco-eletronico/)

## Diretrizes de uso

- No Android, abra o link no Chrome e toque em **Instalar app**. No iPhone ou iPad, abra no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- Depois da primeira abertura online, o app pode funcionar offline. Esboços, histórico e preferências ficam armazenados localmente no aparelho.
- Para trocar de aparelho, use **Histórico → Salvar backup** e importe o arquivo no aparelho de destino em **Restaurar backup**. A restauração substitui os dados locais após confirmação.
- Ao relatar problemas no GitHub, evite incluir esboços pessoais ou informações de terceiros.
