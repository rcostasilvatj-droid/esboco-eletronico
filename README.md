# Esboço Eletrônico

Aplicativo web instalável para organizar esboços de discursos e a presidência da reunião pública.

**by Ricardo Silva**

[Abrir o Esboço Eletrônico](https://rcostasilvatj-droid.github.io/esboco-eletronico/)

## Diretrizes de uso

- Use a versão oficial para abrir e instalar o aplicativo. Para indicar o projeto a outras pessoas, compartilhe o link acima.
- No Android, abra o link no Chrome e toque em **Instalar app**. No iPhone ou iPad, abra no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- Os esboços ficam no armazenamento local do navegador ou do app instalado. Guarde uma cópia dos textos importantes antes de limpar os dados do site ou trocar de aparelho.
- Ao enviar sugestões ou relatar problemas no GitHub, evite incluir esboços pessoais ou informações de terceiros.
